# Context HEAD

Consulte `CONTEXT_HEAD.md` no Agent OS quando disponível. Se não estiver acessível, siga este fallback sem afirmar que leu o arquivo:

1. Identifique a tarefa, projeto e escopo exatos; não infira namespace ou autoridade de tenant.
2. Faça recuperação seletiva e **antes da resposta**: Git/branch/PR/CI/runtime para estado do projeto; Memory privada para preferência durável; Engram para episódio; Drive para especificações e handoffs; PersistFlow para RUN_ID e checkpoints.
3. Só use Context Gateway quando a autenticação e o namespace estiverem comprovados. O índice da Operação 50/50 não é o índice de todos os projetos.
4. Distinguir OBSERVED_REMOTE/LOCAL, REPORTED_LOCAL, HISTORICAL e NOT_VERIFIED; verificar atualizações após antigos handoffs.
5. Se a fonte estiver desconectada, usar fallback direto do **mesmo escopo** e declarar `source unavailable`. Não afirmar que ChatGPT tem invocação automática garantida.
6. Após trabalho durável, aplicar gate de ingestão proporcional. Nunca exportar segredos ou ampliar escopo.

O Windows pode estar desligado; não provisionar infraestrutura paga nem criar um segundo RAG.
